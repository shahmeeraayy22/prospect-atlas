# Prospect Atlas — Local Quick Start

1. Double-click **Start Prospect Atlas.cmd**.
2. Wait for the browser to open at <http://localhost:8080>.
3. Enter a business type and location, choose **Quick test**, and start the search.
4. Open completed results to filter, score, deduplicate, and export leads.
5. Double-click **Stop Prospect Atlas.cmd** when finished.

Docker Desktop must remain installed. Saved searches and CSV files stay in the `gmapsdata` folder.
